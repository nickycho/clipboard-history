# Product Requirements Document — ClipboardHistory

## 產品概述

ClipboardHistory 是一個 macOS menu bar app，自動記錄剪貼簿的文字歷史，讓使用者快速找回先前複製的內容。

## 目標使用者

軟體工程師與日常需要頻繁複製貼上的 Mac 使用者。

## 功能需求

### F1：Menu Bar 常駐

- App 常駐於 menu bar，不出現在 Dock
- Menu bar icon 點擊後開啟 Popover
- App 預設於登入時自動啟動

### F2：Clipboard 監聽

- 自動偵測剪貼簿內容變更（文字類型）
- 每 0.5 秒輪詢一次
- **排除**：非文字內容（圖片、檔案等）
- **排除**：被標記為 `concealed` 的內容（密碼管理器敏感資料）

### F3：History 列表

- 最多保留 **500 筆**文字歷史
- 超過上限時，自動刪除最舊的非我的最愛項目
- 完全去重：相同內容再次複製時，更新時間戳並移到最頂端
- 每筆顯示：
  - 文字內容（單行，超出截斷為 `...`）
  - 複製時間（相對時間，例如「3 分鐘前」）

### F4：搜尋

- Popover 頂部提供搜尋框
- 即時篩選符合的 history 項目（case-insensitive）
- 搜尋範圍：文字內容

### F5：複製

- 點擊（或鍵盤 Enter）任一 history item，將其內容寫回剪貼簿
- 操作完成後自動關閉 Popover

### F6：我的最愛

- 每筆 item hover 時，右側出現星星（☆）按鈕
- 點擊星星切換「加入/移除我的最愛」
- Popover 頂部有兩個分頁：**History** / **我的最愛**
- 我的最愛分頁顯示所有已加星號的項目
- 我的最愛項目不受 500 筆上限刪除影響

### F7：全域快捷鍵

- 固定快捷鍵：`⌘⇧V`
- 在任何 app 下皆可觸發，顯示/隱藏 Popover

### F8：鍵盤導航

Popover 開啟後：
- `↑` / `↓`：在列表中移動選擇
- `Enter`：複製選中項目並關閉 Popover
- `Esc`：關閉 Popover

### F9：自動啟動設定

- App 內 Preferences 提供「登入時啟動」開關
- 預設為**開啟**

## 非功能需求

| 項目 | 規格 |
|------|------|
| 最低 macOS 版本 | macOS 14 Sonoma |
| Popover 尺寸 | 480 × 600（固定） |
| Polling interval | 0.5 秒 |
| History 上限 | 500 筆 |
| 資料持久化 | 是（重開 app 後 history 保留） |
| 發佈方式 | Direct download `.dmg` + Notarize |

## UI 規格

### Popover 佈局

```
┌─────────────────────────────────────┐
│  [History]  [我的最愛]              │  ← 分頁切換
├─────────────────────────────────────┤
│  🔍 搜尋...                         │  ← 搜尋框
├─────────────────────────────────────┤
│  這是複製的文字內容...    3 分鐘前  │  ← item row
│  另一筆複製的內容...      10 分鐘前 │
│  ...                                │
│                                     │
│                                     │
└─────────────────────────────────────┘
```

### Item Row（Hover 狀態）

```
│  文字內容截斷...          3 分鐘前 ☆│
```
